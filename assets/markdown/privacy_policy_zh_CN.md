# Hyve 隐私政策

**更新日期：2026年08月10日**

**生效日期：2026年08月10日**

Hyve 是一款本地优先的 AI 助手客户端。本政策由应用分发页面所标示的 Hyve 开发者或运营主体（以下简称“我们”）制定，用于说明 Hyve 如何处理与您有关的信息，以及您如何进行控制。

## 核心摘要

- **无需 Hyve 账号**：当前版本不要求注册或登录 Hyve 账号，也不收集账号密码。
- **默认本地保存**：个人资料、智能体配置、项目和多数功能数据默认保存在您的设备上。
- **由您选择数据去向**：使用云端 AI、远程 MCP、自定义接口或其他联网功能时，必要数据会直接从您的设备发送给您选择的第三方。
- **不做广告画像**：当前版本未集成广告、用户行为分析或崩溃分析服务，也不会出售您的个人信息。
- **权限按需使用**：相机、照片或文件权限仅在您主动使用相应功能时请求。

请完整阅读本政策。对于敏感权限或依法需要单独同意的处理活动，我们会在具体功能中另行提示。若您不同意某项可选处理，可不启用相应功能。

## 1. 适用范围与处理角色

本政策适用于 Hyve 应用本身。第三方 AI 服务商、MCP 服务、Skill 下载源、自定义接口、外部链接以及操作系统提供的分享或文件选择服务，可能作为独立的数据处理者处理信息，并适用其各自的隐私政策。

Hyve 通常作为本地客户端按照您的指令处理数据。您决定连接哪个服务、提交什么内容以及是否批准工具调用。请不要将不应交由第三方处理的信息发送给相关服务。

## 2. 我们处理的信息

### 2.1 保存在设备上的信息

为提供功能，Hyve 可能在您的设备上处理并保存：

- **个人资料与偏好**：您设置的昵称、头像、语言、主题、字体大小和界面偏好；
- **智能体与服务配置**：智能体名称、头像、模型服务商、模型、接口地址、系统提示词、参数、MCP 服务和 Skill 配置；
- **凭据信息**：您填写的 AI 服务 API Key，以及 MCP 访问令牌或本地服务环境变量；
- **项目内容**：您的输入、AI 回复、推理内容、项目摘要或记忆、附件、生成文件及其本地路径；
- **执行与用量记录**：工具调用、命令执行、文件编辑、Skill 激活状态、错误状态、耗时和 Token 用量；
- **安全与配置记录**：与 Skill 安装、签名、授权、策略和审计有关的本地记录。

当前版本不会为了创建 Hyve 账号而收集您的手机号、电子邮箱或密码。除非您主动在提示词、文件、配置或反馈中提供，我们也不会主动要求您的真实身份信息。

### 2.2 发送给您所选第三方的信息

当您主动使用相关功能时，下列信息可能直接发送至您选择或配置的服务：

- **AI 模型服务**：您的提示词、为保持上下文所需的历史消息或摘要、系统指令、所选附件、工具定义与工具结果，以及模型和生成参数；
- **MCP 或其他工具服务**：服务器连接信息、工具名称、调用参数、必要的项目内容以及工具执行结果；
- **自定义接口或本地模型**：您配置的地址所要求的请求内容和认证信息；
- **Skill 或资源来源**：安装或更新 Skill 时所请求的仓库、目录、压缩包或目录服务信息；
- **系统功能**：您主动分享、导出、保存或打开内容时，相关文件或文本会交给您选择的系统应用或目标应用。

第三方服务还可能自动获得您的 IP 地址、请求时间、设备或网络的常规连接信息。其收集范围、保存期限、训练使用、跨境传输和删除机制由相应第三方决定，请在使用前查阅其政策。

### 2.3 设备权限

- **相机**：仅在您选择拍照添加图片时使用；
- **照片或媒体访问**：仅在您选择图片、视频或保存生成内容时使用；
- **文件访问**：仅在您通过系统选择器选择附件、Skill 包或保存文件时使用；
- **网络访问**：用于连接您选择的 AI、MCP、自定义接口、Skill 来源或外部链接。

您可以在操作系统设置中撤回权限。撤回后，相应功能可能无法使用，但不会影响不依赖该权限的功能。当前版本不请求精准位置、通讯录或麦克风权限。

## 3. 处理目的与依据

我们仅在实现明确功能所需的范围内处理信息，主要用于：

- 保存和恢复您的本地配置、项目与偏好；
- 按照您的指令向所选服务发起请求并展示结果；
- 执行您批准或配置的工具、MCP 与 Skill；
- 统计本地 Token 用量、管理上下文、排查本地错误和维护数据一致性；
- 保障凭据、安装包、工具执行和本地数据的安全；
- 履行适用法律要求或保护您、他人及应用的合法权益。

处理依据可能包括履行您作为一方的协议、您的同意、履行法定义务或适用法律允许的其他依据。对于可选权限和敏感个人信息，我们会在必要时另行取得授权或单独同意。

## 4. 信息共享、委托与跨境传输

1. 我们不会出售或出租您的个人信息，也不会将本地项目用于广告画像。

2. 除您主动选择的第三方服务、依法需要提供、保护重大合法权益或企业依法重组等情形外，我们不会主动向其他主体提供您的个人信息。

3. 您选择的服务商或自定义接口可能位于您所在国家或地区之外。数据是否跨境取决于服务端点和服务商安排。在向境外服务发送个人信息前，请确认您有权这样做，并查阅其数据位置、跨境机制和隐私条款。

4. 如果未来我们引入自有云同步、遥测、广告或其他会改变当前数据流的服务，会在启用前更新本政策，并依法履行告知和同意义务。

## 5. 存储位置与保存期限

1. 本地数据库、项目附件、生成文件、Skill 和摘要文件通常保存在应用数据目录中，并持续保存到您在应用内删除相关内容、清除应用数据或卸载应用为止。

2. AI API Key 会先加密再写入本地数据库；用于加密的密钥和 MCP 凭据存放在操作系统提供的安全存储中。项目正文和普通附件通常不会由 Hyve 再单独加密，而是依赖设备、操作系统和文件系统的安全措施。

3. 您导出、分享、保存到系统相册或复制到其他目录的内容不再由应用内删除功能控制。操作系统或用户启用的设备备份也可能保留副本。

4. 第三方收到的数据由其按照自身政策保存。删除 Hyve 中的本地记录不会自动删除第三方已经接收的数据；如需删除，请使用第三方提供的机制或联系相应服务商。

## 6. 您的权利与控制方式

根据适用法律，您可能享有知情、决定、限制或拒绝处理、查阅、复制、更正、删除以及撤回同意等权利。您可以：

- 在个人资料或设置页面修改本地资料和偏好；
- 清空或删除项目，删除智能体、MCP 服务或已安装 Skill；
- 移除 API Key、访问令牌、自定义接口或其他连接配置；
- 在系统设置中撤回相机、照片、文件等权限；
- 清除应用数据或卸载应用，以删除设备上的应用数据；
- 通过应用分发页面公布的开发者联系方式提出隐私请求。

为保护数据安全，我们可能需要在处理请求前核验请求人与相关设备或数据的关系。对于第三方保存的数据，请直接向相应第三方行使权利。

## 7. 安全措施与您的责任

我们采用本地存储、凭据安全存储、API Key 加密、权限确认、工具风险分级、Skill 校验和可用时的沙箱隔离等措施降低风险。但任何存储、传输或软件系统都无法保证绝对安全。

请为设备设置访问密码并及时安装安全更新，不要共享 API Key，不要连接未知 MCP 地址或安装不可信 Skill。向 AI 提交内容前，请移除不必要的身份证件、金融账户、医疗健康、精确位置、未成年人信息、商业秘密等敏感内容。

## 8. 未成年人信息

Hyve 不专门面向不满14周岁的未成年人。未成年人应在监护人指导下使用。处理不满14周岁未成年人的个人信息依法属于敏感个人信息；如确有必要使用相关功能，应由监护人审慎决定，并避免向第三方模型或工具提交此类信息。

如果您认为未成年人的信息被不当处理，请通过本政策列明的方式联系我们，我们会依法协助处理我们能够控制的数据。

## 9. 政策更新

我们可能因功能、第三方服务、数据处理方式或法律要求变化而更新本政策，并更新文首日期。实质影响您权益的变更会通过应用内提示、更新说明或分发页面等合理方式告知；依法需要取得同意的，我们会在相关处理开始前征求同意。

## 10. 联系我们

如对本政策或个人信息处理有疑问、意见或请求，您可以通过应用分发页面公布的开发者联系方式与我们联系。若您所使用的发行版本另行提供有效的反馈通道，也可以通过该通道联系。
