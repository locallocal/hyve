# Stars 用户协议

**更新日期：2026年08月10日**

**生效日期：2026年08月10日**

欢迎使用 Stars。Stars 是一款本地优先的 AI 助手客户端，可连接您选择或配置的 AI 模型服务、MCP 服务和其他工具。本协议由您与应用分发页面所标示的 Stars 开发者或运营主体（以下简称“我们”）订立。

请在使用 Stars 前完整阅读本协议和《隐私政策》，尤其是第三方服务、AI 输出、工具执行、责任限制和未成年人保护相关条款。当前版本不要求注册 Stars 账号。您开始使用 Stars，即表示您同意受本协议约束；依法需要单独同意的事项，我们会另行征求您的同意。如果您不同意，请停止使用本应用。

## 1. 服务说明

1. Stars 提供本地会话管理、AI 对话、文本或多媒体生成、智能体配置、上下文记忆、Skill、MCP 连接及工具调用等功能。实际可用功能取决于设备平台、应用版本、您选择的模型服务商和您的配置。

2. Stars 本身通常不提供基础模型能力。您发送请求时，本应用会按照您的选择，将完成请求所需的内容直接从您的设备传输给相应的 AI 服务商、自定义接口或 MCP 服务。

3. 部分功能属于实验性功能，可能存在错误、中断、兼容性变化或结果不稳定。我们可能为了安全、合规或产品改进调整、暂停或停止部分功能；涉及您权益的重大变化，我们会以合理方式提示。

## 2. 使用条件与用户责任

1. 您应具备与使用本应用相适应的民事行为能力。未成年人应在监护人阅读并同意本协议后使用，并避免向 AI 或第三方服务提交敏感个人信息。

2. 您应确保有权使用所配置的 API Key、模型账号、MCP 服务、文件、提示词和其他资源，并自行妥善保管设备及相关凭据。

3. 您应对通过本应用发起的请求、工具操作、生成内容的使用以及由此产生的第三方费用负责。请关注模型调用、网络、存储或其他服务可能产生的费用和配额消耗。

## 3. 第三方服务

1. Stars 允许您连接第三方 AI 服务商、本地模型、自定义接口、MCP 服务、Skill 来源或外部链接。第三方服务由相应服务商独立提供，并适用其服务条款、隐私政策、内容规则、计费方式和可用性承诺。

2. 在启用第三方服务前，您应确认服务商身份、请求地址、数据处理规则和收费标准。自定义地址可能由未知主体运营，请勿向不可信地址发送个人信息、商业秘密或其他敏感数据。

3. 对于第三方服务的内容、行为、安全性、持续可用性或收费，在法律允许的范围内应由相应第三方负责。Stars 对某项服务的支持不代表我们对其作出背书或保证。

## 4. 用户内容与 AI 生成内容

1. 您对合法上传、输入或创建的内容保留原有权利。为完成您主动请求的功能，您授权 Stars 在必要范围内于设备上处理相关内容，并将必要内容传输给您选择的第三方服务。该授权仅用于提供和保障您正在使用的功能，不转移内容所有权。

2. 您应确保输入、上传、处理或传播的内容不侵犯他人的隐私、个人信息、肖像、名誉、著作权、商标权、商业秘密或其他合法权益。未经合法授权，请勿提交他人的敏感个人信息或保密资料。

3. AI 输出由概率模型生成，可能包含错误、虚构、偏见、不适当内容或与他人内容相似的表达。您应在使用、发布或据此采取行动前进行人工核验，不应将其作为医疗、法律、金融、安全或其他高风险事项的唯一依据。

4. 您传播 AI 生成或合成的文本、图片、音频、视频等内容时，应按照适用法律和发布平台规则进行必要标识，不得删除、篡改或规避依法设置的生成合成内容标识，不得冒充真人或误导公众。

## 5. 工具、MCP 与 Skill 风险

1. 经您配置或授权后，模型可能请求调用 MCP 工具、读取文件、执行命令、安装或运行 Skill 等。这些操作可能访问网络、读取或修改本地文件、启动进程，或向第三方发送工具参数和结果。

2. 请在批准工具调用前核对工具来源、权限范围、参数、目标文件和风险提示。仅安装可信 Skill，仅连接可信 MCP 服务，并为重要数据保留独立备份。

3. 即使应用提供权限确认、风险分级、签名验证或沙箱隔离，也不能消除所有风险。您主动批准、配置为免确认或通过外部组件执行的操作，可能产生不可逆的数据变更或外部影响。
